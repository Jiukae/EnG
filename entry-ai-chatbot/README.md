# 엔트리 AI 챗봇 '엔봇'

[엔트리(playentry.org)](https://playentry.org)에서 불러와 바로 실행할 수 있는 블록 코딩 챗봇 작품입니다.
사용자(엔트리 계정)마다 **대화 기록과 가르친 지식이 따로 저장**되고, 다시 접속하면 이어서 대화합니다.

- 작품 파일: [`entry-ai-chatbot.ent`](entry-ai-chatbot.ent)
- 블록 수: 약 2,200개 (스크립트 11개, 오브젝트 2개)

## 할 수 있는 일

| 입력 예시 | 동작 |
| --- | --- |
| `안녕`, `심심해`, `오늘 너무 힘들어` | 키워드 지식 베이스(62개 항목)에서 골라 대답 |
| `기억해: 내 생일 = 3월 14일` | 나만의 지식 가르치기 → 내 계정에 저장 |
| `내 생일이 언제야?` | 가르친 지식으로 대답 (가장 길게 일치하는 질문 우선) |
| `잊어줘: 내 생일`, `기억 목록` | 가르친 지식 지우기 / 모두 보기 |
| `번역: 오늘 날씨가 좋아요` | 엔트리 **인공지능 번역 블록(파파고)** 으로 영어 번역 |
| `한국어로: Nice to meet you` | 영어 → 한국어 번역 |
| `계산: 12*3`, `계산: 10/4` | 사칙연산 (+ - * / 중 하나, ×·÷·x 도 됨) |
| `몇 시야?`, `오늘 며칠이야?` | 현재 시각 / 날짜·요일 |
| `새 대화` | 내 대화 기록 지우기 (가르친 지식은 유지) |
| `도움말`, `종료` | 사용법 보기 / 대화 끝내기 |

로그인한 사람은 닉네임으로 불러 주고, 다시 실행하면 "지난 대화"를 보여 준 뒤 이어서 대화합니다.

### 솔직하게 알려 드릴 점

- **ChatGPT 같은 생성형 AI는 아닙니다.** 엔트리 블록 중에는 대규모 언어 모델(LLM)을 부르는 블록이 없습니다
  (entryjs 소스에서 확인). 그래서 키워드 지식 베이스 + 사용자가 가르친 지식 + 파파고 번역 AI 를 조합한 방식입니다.
  `키워드` / `키워드답변` 리스트에 줄을 추가하면 더 많은 말을 알아듣게 만들 수 있습니다.
- **"사용자별 저장"은 공유 저장소 안에서 계정 아이디로 칸을 나누는 방식입니다.** 모든 사용자의 데이터가
  작품의 실시간 리스트 `대화기록`, `기억저장소` 에 `아이디|내용` 형태로 들어갑니다. 화면에는 숨겨져 있지만
  작품 코드를 열어 볼 수 있는 사람은 볼 수도 있으니, **비밀번호·전화번호 같은 개인정보는 입력하지 말라고**
  작품 설명에 꼭 적어 주세요.
- 로그인하지 않은 사람도 대화는 할 수 있지만 저장되지 않습니다.

## 엔트리에 올리고 배포하는 방법

> 회원가입·작품 공유는 본인 계정으로 직접 하셔야 합니다. (이 작업 환경에서는 playentry.org 접속이 막혀 있었고,
> 회원가입은 약관 동의와 본인 이메일 인증이 필요하기 때문에 대신할 수 없습니다.)

1. **회원가입**: playentry.org 오른쪽 위 `회원가입` → 아이디·비밀번호·닉네임 등을 입력하고 약관에 동의합니다.
   만 14세 미만은 보호자 동의가 필요할 수 있고, 작품 공유 전에 이메일 인증을 요구할 수 있습니다.
2. **작품 불러오기**: 로그인 → `만들기` → `작품 만들기` 로 만들기 화면을 엽니다.
   위쪽 메뉴(폴더 모양)에서 **`오프라인 작품 불러오기`** 를 고르고 `entry-ai-chatbot.ent` 를 선택합니다.
   (메뉴 이름은 엔트리 업데이트에 따라 조금 다를 수 있습니다.)
3. **확인**:
   - 블록 꾸러미의 `인공지능` 탭에 `번역` 블록이 켜져 있어야 합니다. 꺼져 있다면 `인공지능 블록 불러오기` 에서
     `번역` 을 추가해 주세요.
   - `속성` 탭 → `리스트` 에서 `대화기록`, `기억저장소` 가 **실시간 리스트** 인지 확인합니다.
4. **실행해 보기**: ▶ 시작하기 → 아래 입력창에 `도움말`, `기억해: 내 취미 = 축구`, `내 취미가 뭐야?` 를 차례로
   입력해 봅니다. 대화가 느리면 실행 화면의 **부스트 모드** 를 켜 주세요 (반복 블록이 훨씬 빨라집니다).
5. **저장**: 작품 이름(예: `엔트리 AI 챗봇`)을 정하고 `저장하기`.
6. **배포(공유)**: `작품 공유하기` 에서 공개로 설정합니다. 작품 설명에 사용법(`도움말` 입력)과
   "개인정보를 입력하지 마세요" 안내를 적어 주세요.
7. **공유 후 저장 확인 (중요)**: 공유된 작품 페이지에서 로그인한 상태로 실행 → `기억해: 테스트 = 성공` 입력 →
   ■ 정지 → 다시 실행했을 때 `── 지난 대화 ──` 와 함께 기록이 보이고 `테스트` 에 `성공` 이라고 답하면
   사용자별 저장이 제대로 되는 것입니다. 다른 계정(친구)으로 실행하면 그 사람의 기록은 따로 시작됩니다.

### 저장이 안 될 때

- 만들기 화면(저장 전)에서는 실시간 리스트가 서버에 연결되지 않아, 대화가 그 자리에서만 유지될 수 있습니다.
  작품을 저장·공유한 뒤 **공유 페이지에서** 7번 확인을 해 주세요.
- 시작할 때 `(저장 서버에 연결하지 못해서 …)` 가 나오면 이번 실행은 저장되지 않습니다. 잠시 뒤 다시 실행해 보고,
  계속 그렇다면 `속성` 탭에서 `대화기록`, `기억저장소` 가 실시간 리스트로 들어왔는지 확인해 주세요.

## 작품 구조 (블록 설계)

오브젝트 `챗봇`(글상자) 하나에 모든 스크립트가 있고, `제목` 글상자는 장식입니다.

| 스크립트 | 하는 일 |
| --- | --- |
| 시작하기 버튼을 클릭했을 때 | 로그인 확인 → 내 데이터 불러오기 → `묻고 기다리기` 반복 |
| 신호 `답변 만들기` | 명령(도움말·기억해·잊어줘·번역·계산·새 대화·종료) → 내 지식 → 시간/날짜 → 키워드 → 모르는 말 순서로 답 결정 |
| 신호 `채팅에 출력` | `¶` 로 줄을 나누고, 긴 줄은 24글자(띄어쓰기 기준)로 잘라 `대화창` 리스트에 넣음. 최근 9줄만 유지 |
| 신호 `사용자 데이터 불러오기` | 실시간 리스트에서 내 칸(`아이디|`로 시작)을 찾고, 없으면 새로 만듦 |
| 신호 `기록에 추가` / `기록 저장` | 내 대화를 최근 30줄까지 한 문자열로 모아 내 칸에 덮어씀 |
| 신호 `기억 저장` | `질문=답¶질문=답¶…` 형태로 내 칸에 덮어씀 (최대 30개) |
| 신호 `계산하기`, `공백 정리`, `기록/기억 위치 찾기` | 보조 기능 |

여러 사람이 동시에 실행해도 서로의 데이터를 덮어쓰지 않도록, 각 사용자는 **처음 한 번만 리스트에 항목을 추가**하고
그 뒤에는 **자기 칸만 바꾸기**를 합니다. (항목을 지우지 않으므로 칸 번호가 바뀌지 않습니다.)

## 개발자용

```bash
python3 build_project.py   # project.json, entry-ai-chatbot.ent 다시 만들기
python3 test_chatbot.py    # 구조 검사 + 시뮬레이션 테스트
python3 simulate.py 내아이디  # 터미널에서 대화해 보기 (빈 줄 입력 시 종료, 번역은 가짜로 표시)
```

- `build_project.py`: 블록을 파이썬으로 조립해 .ent(= `temp/project.json` 을 담은 tar.gz)를 만듭니다.
  블록 이름과 파라미터 순서는 [entrylabs/entryjs](https://github.com/entrylabs/entryjs) 의
  `src/playground/blocks/*.js` 정의를 따릅니다.
- `simulate.py`: 엔트리 블록의 동작(자바스크립트 형 변환, 리스트 범위 오류 등)을 옮긴 간이 실행기입니다.
- `test_chatbot.py`: 모든 블록의 파라미터 개수·종류·드롭다운 값을 entryjs 정의와 비교하고, 여러 사용자가 번갈아
  쓰는 상황과 무작위 입력 150회에서 블록 오류가 나지 않는지 확인합니다.

이 작품 파일은 위 검사들로 확인했지만, 실제 엔트리 화면에서 불러와 본 것은 아닙니다. 불러오다 문제가 생기면
알려 주세요.
