# 엔봇 — 기억하는 AI 친구 (엔트리 블록 코딩 챗봇)

[엔트리(playentry.org)](https://playentry.org)에서 불러와 바로 실행할 수 있는 블록 코딩 챗봇 작품입니다.
정해 둔 문장을 돌려주지 않고, **사용자의 문장을 분석해서** 공감하고, 되묻고, 들은 내용을 기억합니다.
기억은 엔트리 계정마다 따로 저장되어, 다시 접속하면 지난 이야기를 이어 갑니다.

- 작품 파일: [`entry-ai-chatbot.ent`](entry-ai-chatbot.ent)
- 오브젝트 27개 (모두 글상자), 블록 약 10,600개

![엔봇 미리보기](preview.png)

> 위 그림은 실제 엔트리 화면을 캡처한 것이 아닙니다. 시뮬레이터로 대화를 돌린 뒤, 작품 파일 속 글상자 설정(위치·정렬·색)대로
> 다시 그린 미리보기입니다 (`preview.py`). 글꼴과 입력창 모양은 실제와 조금 다를 수 있습니다.

## 실제 대화 예시

아래는 작품의 블록을 그대로 실행하는 시뮬레이터(`simulate.py`)로 얻은 대화입니다.
(번역 블록만 가짜 번역기로 바꿔 돌립니다.)

```
봇: 안녕하세요, 민수님! 저는 엔봇이에요. 이야기하면서 민수님에 대해 하나씩 기억해 둘게요. 오늘 하루는 어땠어요?
나: 오늘 시험 망쳤어
봇: 오늘 시험 망쳤군요. 많이 힘들었겠어요. 제가 들어 줄게요. 어떤 일이었어요?
나: 수학 시험이었어
봇: 수학 시험이었군요. 그런 일이면 누구라도 힘들었을 거예요. 너무 마음 쓰지 말아요. 제가 응원할게요!
나: 나 고양이 키워
봇: 고양이 이야기군요! 고양이 이름이 뭐예요?
나: 나비
봇: 민수님의 고양이 이름은 나비군요! 기억해 둘게요.
나: 블랙홀이 뭐야?
봇: 블랙홀은 중력이 너무 강해서 빛조차 빠져나오지 못하는 우주의 천체예요.
나: 양자컴퓨터가 뭐야?
봇: 양자컴퓨터? 처음 들어 봐요. 어떤 건지 알려 줄래요?
나: 양자의 원리로 계산하는 컴퓨터야
봇: 양자컴퓨터는 양자의 원리로 계산하는 컴퓨터군요! 새로 배웠어요. 고마워요.
```

다음 날 다시 접속하면:

```
── 지난 대화 ── (위 대화가 다시 보임)
── 이어서 이야기해요 ──
봇: 민수님, 다시 왔군요! 지난번에 고양이 이야기를 했었죠. 그 뒤로 어떻게 됐어요?
나: 나비가 요즘 밥을 안 먹어
봇: 민수님의 고양이 나비 말이죠? 고양이 때문에 속상했겠어요. 제가 들어 줄게요. 어떤 일이었어요?
나: 양자컴퓨터 알아?
봇: 양자컴퓨터는 양자의 원리로 계산하는 컴퓨터라고 했어요!
나: 내 생일은 3월 14일이야
봇: 아하, 민수님의 생일은 3월 14일이군요. 잘 기억할게요!
나: 나는 피자를 좋아해
봇: 오, 피자를 좋아하는군요. 저도 기억할게요! 피자 맛있죠! 어떤 피자를 제일 좋아해요?
나: 내가 뭐 좋아한다고 했지?
봇: 제 기억으로는 민수님이 좋아하는 것은 피자예요.
```

## 엔봇이 생각하는 방법

메시지를 받을 때마다 신호 `답변 만들기`가 아래 순서로 돌아갑니다.

1. **문장 분석** (`두뇌1 문장 분석`)
   - 낱말로 나누고 조사(은/는/이/가/을/를/에서/한테/랑…)를 떼어 냅니다.
   - 주제(시험, 친구, 고양이 등 105개)를 찾고, 질문인지 판단하고, 감정 점수(긍정어 44개, 부정어 54개)를 셉니다.
   - 되받을 말을 만듭니다: "시험 망쳤어" → "시험 망쳤군요", "치킨 먹고 싶어" → "치킨 먹고 싶군요",
     "나 중학생이야" → "중학생이군요". "나/내가"는 빼고 "내"는 "민수님"으로 바꿉니다.
   - 말 속에 기억해 둔 값이 있으면 알아봅니다 ("나비" → 고양이 이름).
2. **대화 상태**: 직전에 엔봇이 무엇을 물었는지 기억합니다. 고양이 이름을 물었으면 다음 대답("나비")을
   '내 고양이 이름'으로 저장하고, 이유를 물었으면 다음 말을 앞 이야기와 이어서 받아 줍니다.
   "몰라", "그냥" 같은 대답은 저장하지 않습니다.
3. **이야기 속 사실 기억**: "내 X는 Y야", "내 이름은 ○○야", "나 ○○ 좋아해/싫어해", "나 12살이야"에서 사실을 뽑아 둡니다.
4. **기억에서 찾기**: "내 생일 언제라고 했지?", "내가 뭐 좋아한다고 했지?"에 기억으로 대답합니다.
5. **아는 단어 뜻**(56개) → **일상 대화**(인사, 감사, 엔봇에 대한 질문 등) → **모르는 단어는 물어보고 배우기**.
6. **공감**: 걱정·부정·긍정에 맞춰 공감하고, 주제에 맞는 질문으로 이어 갑니다. 이미 아는 것은 다시 묻지 않습니다.
7. 모르는 질문은 답을 알려 달라고 하고 배웁니다. 이야기가 끊기면 아직 모르는 것(취미, 꿈, 좋아하는 음식…)을 먼저 묻습니다.

받침에 맞춰 조사를 고르는 블록(`조사 붙이기`)이 있어서 "생일은 3월 14일이군요", "꿈은 의사군요"처럼 자연스럽게 말합니다.

### 솔직하게 알려 드릴 점

- **ChatGPT 같은 대형 언어 모델은 아닙니다.** 엔트리에는 언어 모델을 부르는 블록이 없습니다(entryjs 소스에서 확인).
  엔봇은 위의 규칙들로 문장을 이해하므로, 복잡하거나 낯선 문장은 엉뚱하게 받아들일 수 있습니다.
  번역만 엔트리의 인공지능 번역 블록(파파고)을 씁니다.
- **완전히 비공개는 아닙니다.** 모든 사용자의 기록이 작품의 실시간 리스트 `대화기록`, `기억저장소`에
  `아이디|내용` 형태로 들어갑니다. 작품 설명에 **"개인정보는 입력하지 마세요"** 라고 꼭 적어 주세요.
- 로그인하지 않으면 대화는 되지만 저장되지 않습니다.
- 부스트 모드가 꺼져 있으면 대답까지 1초 남짓 걸립니다 ("엔봇이 생각하는 중…" 이 표시됩니다).
- 이 파일은 아래 검사들로 확인했지만, **실제 엔트리에서 불러와 실행해 본 것은 아닙니다.**

## 화면 디자인 (글상자)

| 오브젝트 | 역할 |
| --- | --- |
| `헤더`, `제목`, `부제`, `상태` | 남색 머리 띠, "🤖 엔봇 · 기억하는 AI 친구", 오른쪽 상태 표시(● 민수님과 대화 중 / ● 생각하는 중…) |
| `봇칸1`~`봇칸9` | 왼쪽 정렬 흰 말풍선 줄 (엔봇의 말, 회색 안내 줄, 생각 중 표시) |
| `나칸1`~`나칸9` | 오른쪽 정렬 남색 말풍선 줄 (내 말) |
| `대화배경` | 대화 영역의 연회색 바탕 |
| `엔봇` | 입력 안내 문구 + 메인 스크립트 |
| `두뇌1`~`두뇌3` (숨김) | 문장 분석 / 대답 만들기 / 기억 — 블록이 많아 작업창이 무거워지지 않게 나눔 |

말풍선 줄은 리스트 `화면글`, `화면종류`의 최근 9줄을 신호 `화면 그리기` 때마다 다시 그립니다.
긴 말은 띄어쓰기 기준으로 24글자씩 나눠 여러 줄로 보여 줍니다. `묻고 기다리기`의 말풍선은 지우고, 안내 글상자로 대신합니다.

## 엔트리에 올리고 배포하는 방법

> 회원가입과 공유는 본인 계정으로 직접 하셔야 합니다 (약관 동의와 이메일 인증이 필요합니다).

1. **회원가입**: playentry.org 오른쪽 위 `회원가입`. 만 14세 미만은 보호자 동의가 필요할 수 있습니다.
2. **불러오기**: `만들기` → `작품 만들기` → 위쪽 메뉴(폴더 모양)의 **`오프라인 작품 불러오기`** 에서
   `entry-ai-chatbot.ent` 선택. (메뉴 이름은 엔트리 업데이트에 따라 조금 다를 수 있습니다.)
3. **확인**: `인공지능` 블록 꾸러미에 `번역`이 있는지, `속성` 탭에서 `대화기록`·`기억저장소`가 **실시간 리스트**인지 봅니다.
4. **실행**: ▶ 시작하기 → 아래 입력창에 말을 걸어 봅니다. 느리면 실행 화면의 **부스트 모드**를 켜 주세요.
5. **저장 → 작품 공유하기**로 공개합니다. 작품 설명에 사용법과 개인정보 안내를 적어 주세요.
6. **공유 페이지에서 저장 확인 (중요)**: 로그인한 상태로 실행 → `내 생일은 3월 14일이야` → ■ 정지 → 다시 실행해서
   `── 지난 대화 ──`가 보이고 `내 생일 언제라고 했지?`에 날짜로 대답하면 사용자별 저장이 되는 것입니다.

저장이 안 될 때: 만들기 화면(저장 전)에서는 실시간 리스트가 서버에 연결되지 않아 그 자리에서만 기억할 수 있습니다.
공유 페이지에서 6번을 해 보고, 시작할 때 `저장 서버에 연결하지 못해서…`가 나오면 리스트 종류를 확인해 주세요.

### 더 똑똑하게 만들기

블록을 고치지 않아도 리스트만 고치면 됩니다 (`속성` 탭 → 리스트).

| 리스트 | 내용 |
| --- | --- |
| `주제목록` / `주제질문목록` | 주제 낱말과, 그 주제가 나오면 이어서 할 질문 |
| `정의단어` / `정의설명` | "○○가 뭐야?"에 대답할 단어 뜻 |
| `의도키워드` / `의도답변` | 인사·감사 같은 일상 대화 (키워드는 띄어쓰기 없이 소문자) |
| `긍정어`, `부정어` | 감정 점수를 셀 낱말 |
| `시작키` / `시작질문` | 대화가 끊길 때 엔봇이 먼저 물어볼 것 |
| `말-…` | 상황별 문장들 (공감, 되묻기, 기억했을 때 등) |

문장 안의 `{이름}`, `{주제}`, `{주제은}`(받침에 맞춰 은/는), `{값이군요}` 같은 자리 표시와,
문장 끝의 `[이야기]`, `[이유]`, `[기분]`, `[사실:내 꿈]`(다음 대답을 '내 꿈'으로 기억) 표시를 쓸 수 있습니다.

## 명령어

`도움말` · `기억 목록` · `나에 대해 알아?` · `기억해: 질문 = 답` · `잊어줘: 내 생일` ·
`번역: 문장` · `한국어로: sentence` · `계산: 12*3` · `몇 시야?` · `오늘 며칠이야?` · `새 대화` · `종료`

## 개발자용

```bash
python3 build_project.py   # project.json, entry-ai-chatbot.ent 만들기
python3 test_chatbot.py    # 구조 검사 + 대화·저장·화면 테스트 (26개)
python3 preview.py         # preview.png 다시 그리기 (node + playwright 필요)
python3 simulate.py 내아이디  # 터미널에서 대화해 보기 (빈 줄 입력 시 끝)
```

| 파일 | 내용 |
| --- | --- |
| `dsl.py` | 엔트리 블록을 파이썬으로 조립하는 도구 (같은 블록 객체를 두 번 넣으면 자동으로 복사해 id 중복을 막음) |
| `data.py` | 주제·단어 뜻·감정어·문장 등 엔봇의 말과 지식 |
| `build_project.py` | 스크립트와 화면을 조립해 .ent(= `temp/project.json`을 담은 tar.gz) 생성 |
| `simulate.py` | 엔트리 블록 동작(자바스크립트 형 변환, 리스트 범위 오류, 블록 파라미터를 먼저 모두 계산하는 방식, 글상자 상태)을 옮긴 실행기 |
| `test_chatbot.py` | 모든 블록의 파라미터 개수·종류·드롭다운 값을 entryjs 정의와 비교하고, 대화·사용자별 저장·화면·무작위 입력 120회를 검사 |
| `preview.py` | 시뮬레이터 결과로 무대 미리보기 그림 생성 |

블록 이름과 파라미터 순서는 [entrylabs/entryjs](https://github.com/entrylabs/entryjs)의
`src/playground/blocks/*.js` 정의를 따릅니다.
