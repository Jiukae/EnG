# 엔봇 — 기억하는 AI 친구 (엔트리 블록 코딩 챗봇)

[엔트리(playentry.org)](https://playentry.org)에서 불러와 바로 실행할 수 있는 블록 코딩 챗봇 작품입니다.
정해 둔 문장을 돌려주지 않고, **사용자의 문장을 분석해서** 공감하고, 되묻고, 들은 내용을 기억합니다.
메시지는 '묻고 대답 기다리기' 대신 **블록으로 만든 한글 입력기**로, 아래 입력창에 키보드로 치고 **Enter ⏎** 로 보냅니다.
왼쪽 **대화 기록**에서 대화 칸 옆 💾 를 누르면 그 대화와 기억이 엔트리 계정마다 따로 저장되어, 다시 접속했을 때 지난 이야기를 이어 갑니다.

- 작품 파일: [`entry-ai-chatbot.ent`](entry-ai-chatbot.ent) (그림 파일 3개가 함께 들어 있음)
- 오브젝트 41개 (글상자 35개 + 그림 6개) · **함수 77개** · **단어 뜻 1,726개** · 지식 리스트 3,511개 항목 · 신조어 85개 · 끝말잇기 낱말 2,034개 · 테이블 1개(`대화기록표`, 켜서 씀)
- **블록 21,833개** = 오브젝트 스크립트 2,135개 + 함수 속 19,698개

![엔봇 미리보기](preview.png)

> 위 그림은 실제 엔트리 화면을 캡처한 것이 아닙니다. 시뮬레이터로 키를 누르고 칸·💾·버튼을 누른 뒤, 작품 파일 속
> 오브젝트 설정(위치·정렬·색·모양)대로 다시 그린 미리보기입니다 (`preview.py`). 글꼴은 실제와 조금 다를 수 있습니다.

### 블록 수를 셀 때 주의할 점

엔트리 화면에서 오브젝트 `엔봇`을 열면 블록이 **700개**쯤으로 보입니다. 오브젝트에 보이는 건 메인 스크립트와 클릭 처리뿐이고,
실제 일은 함수 77개가 하기 때문입니다. 함수 안의 블록(19,698개)까지 **포함하면 21,833개**입니다.
가장 큰 함수는 `대답: 계산·고르기·날짜`(3,068개), `대답: 명령`(2,037개), `문장 분석`(1,353개)입니다.

## 이번 버전에서 바뀐 것: 표지 · 한글 입력기

### 표지는 ▶ 시작하면 바로 사라져요

작품이 멈춰 있을 때는 대표 이미지와 같은 **표지**(`표지`)가 무대를 덮고 있고, **▶ 시작하면 바로 사라지면서** 챗봇이 시작됩니다.
따로 누르던 `시작하기` 버튼은 없앴습니다. (정지하면 엔트리가 오브젝트를 시작 전 상태로 되돌리므로 표지가 다시 보입니다.)

### 한글 입력기: 키보드로 치고 Enter ⏎ 로 보내기

엔트리의 **'묻고 대답 기다리기'를 쓰지 않습니다.** 무대 아래쪽에 직접 만든 입력창이 있고, 키를 누를 때마다
`키를 눌렀을 때` 스크립트(키 53개)가 글자를 **두벌식으로 조합**해서 보여 줍니다. **Enter ⏎** (또는 오른쪽 ⏎ 버튼)를 누르면 보냅니다.

| 키 | 하는 일 |
| --- | --- |
| 글자 키 | 두벌식 자판대로 자모를 넣고 글자를 조합합니다 (ㄷ → 다 → 달 → 닭 → 닭이). 겹모음(ㅘ ㅝ ㅢ …)과 겹받침(ㄺ ㅄ …), 받침이 다음 글자로 넘어가는 것(닭+ㅣ → 달기)까지 |
| **Shift** + 글자 키 | 쌍자음 ㅃ ㅉ ㄸ ㄲ ㅆ, ㅒ ㅖ / 영어 대문자 / 기호 `! ? @ : ( )` … |
| **Shift + Space** 또는 왼쪽 **[한]** 버튼 | 한글 ↔ 영어 (`/save`, `번역: hello` 같은 영어는 영어 모드에서) |
| **Backspace** | 조합 중이면 자모 하나씩 (닭 → 달 → 다 → ㄷ), 아니면 한 글자씩 지웁니다 |
| **← → Esc** | 조합 중인 글자를 확정합니다 (`좋아ㅋㅋ`처럼 자음만 따로 쓰고 싶을 때) |
| **Enter ⏎** | 보냅니다. 빈 글은 보내지 않고, 엔봇이 대답하는 중에는 기다립니다 |

- 엔트리는 키를 **물리 키 번호**(`event.code`)로 알려 주므로, 컴퓨터의 한/영 상태와 상관없이 두벌식 자리대로 입력됩니다.
  (컴퓨터의 한/영 키는 엔트리에 전달되지 않아서 Shift+Space 로 바꿉니다.)
- 엔트리에는 '번호 → 글자' 블록이 없어서, 가~힣 11,172자를 이은 글(변수 `한글표`)에서
  `초성×588 + 중성×28 + 종성 + 1` 번째 글자를 꺼내 조합합니다.
- 키 스크립트와 그 안의 함수에는 **반복 블록이 없어서** 키 하나를 한 프레임 안에 처리합니다 (빨리 쳐도 순서가 섞이지 않음).
- 한 번에 100자까지 입력할 수 있고, 긴 글은 입력창에 뒷부분만 `…`와 함께 보여 줍니다.
- 테스트: 가~힣 **11,172자를 모두** 섞은 순서로 두벌식으로 쳐서 블록이 조합한 결과가 원래 글과 같은지 검사합니다.
  다른 테스트들도 이제 메시지를 **키 하나하나 눌러서** 입력합니다 (`simulate.py`의 두벌식 타자).

> 참고로 주신 한글 입력기 작품(playentry.org/project/63cde101af47ad004b5dee02)은 이 작업 환경에서 playentry.org 에 접속할 수 없어서
> 열어 보지 못했습니다. 위 입력기는 엔트리 엔진 소스(키 이벤트·`키를 눌렀는가?` 블록)를 보고 새로 만든 것입니다.

- 테스트 90개 → **99개**

## 그 전 버전에서 바뀐 것: 왼쪽 대화 기록 · 💾 저장 아이콘

### 왼쪽 '대화 기록'

대화 화면 왼쪽에 **대화 기록**이 생겼습니다. 대화를 여러 개(최대 5개) 따로 두고 오갈 수 있습니다.

| 누르는 것 | 하는 일 |
| --- | --- |
| **＋ 새 대화** (`/new` 도 같음) | 새 대화를 맨 위에 만듭니다. 맨 위 대화가 아직 비어 있으면 그 대화를 씁니다. 5개가 넘으면 가장 오래된 대화를 목록에서 뺍니다. 기억(내 생일, 고양이 이름 …)은 모든 대화에 이어집니다 |
| **대화 칸** | 그 대화로 바꿉니다. 마지막 몇 줄을 다시 보여 주고, 그 대화에 이어서 기록합니다. 지금 보고 있는 칸은 남색으로 표시됩니다 |
| **💾 (칸마다)** | 그 대화를 저장합니다. 저장된 대화는 💾 가 **초록색 + 체크** 모양(`저장됨`)으로 바뀌고, 저장한 뒤 더 이야기하면 다시 흰 💾 에 주황 점(`저장하기`)이 됩니다 |

- 대화 칸에는 **제목**(그 대화에서 내가 처음 한 말, 길면 `…`로 줄임)과 **날짜**(처음 이야기한 날, `10/26`)가 나옵니다.
- 💾 는 직접 그린 그림입니다 (`assets.py` → `assets/저장하기.png`, `assets/저장됨.png`). 엔트리 모양 두 개를 `모양 바꾸기`로 바꿉니다.
- **저장은 💾 로 합니다.** `/save` 명령도 그대로 되며, 지금 보고 있는 대화를 저장합니다.
  저장하지 않은 대화는 다음에 들어오면 없어지고, 저장한 대화들만 왼쪽에 다시 나옵니다 (가장 최근 대화가 펼쳐짐).
- 저장하지 않은 대화가 있는 채로 `종료`하면 "아직 저장하지 않은 대화가 2개 있어요 …"처럼 개수를 알려 주고 한 번 묻습니다.
- 로그인하지 않았으면 💾 를 눌렀을 때 "💾 저장은 로그인했을 때만 할 수 있어요."라고 알려 줍니다.
- 대답을 만드는 중에 칸이나 💾 를 누르면, 대답이 끝날 때까지 기다렸다가 처리합니다 (변수 `처리중`).
- `/clear`는 **지금 대화**의 기록만, `/clear all`은 모든 대화와 기억을 지웁니다. 둘 다 💾 로 저장하기 전에는 이번 실행에서만 지워집니다.
- 서버(실시간 리스트 `대화기록`)에는 저장한 대화들을 `#대화` 줄로 나눠 한 칸에 담습니다 (대화마다 최근 30줄).
  `#대화` 줄이 없는 예전 저장 형식은 대화 하나로 읽습니다.

- 대화창은 오른쪽으로 옮기고 폭을 368로 줄였습니다. 무대 아래쪽(y < -66)은 입력창 자리입니다.

## 예전 버전에서 바뀐 것: /new · /clear · /save

- **자동으로 저장하지 않습니다.** 저장할 때만 저장하고, 저장하지 않고 나가면 다음에 들어올 때 **마지막으로 저장한 때**로 돌아갑니다.
- 저장하지 않은 내용이 있으면 위쪽 상태 표시가 `● 민수님 · 저장 안 됨`으로 바뀌고, 저장하면 `● 민수님과 대화 중`으로 돌아옵니다.
- 기록을 지울 때 리스트를 한 바퀴에 8줄씩 지우게 해서, 기록 40줄을 지우는 데 316프레임(부스트 모드 없이 약 5초) 걸리던 것이
  41프레임(약 0.7초)으로 줄었습니다. (엔트리에는 리스트를 한꺼번에 비우는 블록이 없어서 한 줄씩 지워야 합니다.)

  예술·스포츠·음악 76 · 음식 75 · 수학 70 · 컴퓨터 54 · 우주 46.
- **낱말 하나만 말해도** 뜻을 알려 줍니다. `장영실` → "장영실은 조선 세종 때의 과학자예요. 해시계, 물시계, 측우기를 만들었어요."
  `블랙홀!`, `광합성?`처럼 문장 부호가 붙어도 됩니다. `학교`처럼 주제 낱말이면 "학교에서는 어떤 시간이 제일 좋아요?"처럼 이어서 묻습니다.
- 낱말 하나여도 이런 때는 원래 대답을 먼저 합니다:
  엔봇이 물어본 것의 대답(예: "좋아하는 동물은?" → `고양이`는 기억, "어떤 과목 시험이었어요?" → `수학`, "왜 그랬어요?" → `숙제`,
  "기분 어때요?" → `행복`) · 기억해 둔 이름(`나비` → "민수님의 고양이 나비 말이죠?") ·
  일상 대화 키워드와 똑같은 말(`수수께끼`, `안녕`) · 명령(`통계`, `구구단`) · 신조어(`야르`).
- `원숭이`, `울릉도`, `민주주의`처럼 끝 글자가 조사(이·도·의)처럼 보이는 낱말도 뜻을 아는 낱말이면 자르지 않습니다.
- "○○가 뭐야?"도 더 잘 찾습니다(`이순신 장군이 누구야?`, `광합성에 대해 알려줘`). 대신 `오늘 학교에서 뭐 배웠는지 알아?`,
  `내 친구 알아?`처럼 내 이야기를 묻는 말에는 사전 뜻을 말하지 않습니다.
- 늘어난 낱말 덕분에 끝말잇기 낱말도 1,273개 → 2,034개가 되었습니다 (사람 이름 같은 고유 명사는 뺌).
- 테스트 69개 → 76개 (단어 뜻 1,700여 개를 하나씩 낱말만 말해 보고 모두 맞는 뜻이 나오는지 검사)

## 예전 버전에서 바뀐 것: 신조어 알아듣기 · 예전 대화 참고

### 신조어 · 초성체

`knowledge/표-신조어.csv`에 85개를 넣었습니다. 한 줄이 세 가지로 쓰입니다.

| 쓰임 | 예 |
| --- | --- |
| 그 말에 대답 | `야르` → "야르~! 😆 신나는 일 있어요?" · `ㅎㅇ` → "ㅎㅇㅎㅇ! 반가워요, 민수님!" · `어쩔티비` → "저쩔티비! 😝" · `ㅂㅇ` → 작별 인사 · `헐`, `ㅋ` (한 글자도) |
| 뜻 알려 주기 | `킹받다가 뭐야?` → "킹받다는 '열받다'를 더 세게 말한 신조어예요." |
| 감정 알아채기 | `친구가 놀려서 진짜 킹받았어` → 속상한 말로 알아듣고 공감 · `개웃겼어`, `핵좋아`처럼 앞에 붙은 개·핵·킹·왕…은 떼고 감정을 찾음 · `시험 잘 봤어`처럼 띄어 쓴 '잘'도 |

- `ㅇㅇ`은 '응', `ㄴㄴ`은 '아니', `ㅁㄹ`·`몰루`는 '몰라'로 알아듣습니다. `반모`라고 하면 반말 모드가 됩니다.
- 엔봇이 "롤모델이 누구예요?"라고 물었을 때 `어쩔티비`, `ㅇㅇ`, `ㅋㅋㅋ`처럼 대답하면 **그걸 롤모델로 기억하지 않습니다.**
- `ㅅㅂ` 같은 욕 초성에는 화난 마음을 먼저 물어보고 고운 말을 권합니다.
- 새 신조어는 CSV에 한 줄 더하고 `python3 build_project.py`로 다시 만들면 됩니다.

### 예전 대화를 참고해서 대답하기

엔봇이 주제마다 **언제, 무슨 말을, 어떤 기분으로** 했는지 `지난 이야기`로 적어 두고(최근 20개 주제), 기억과 함께 계정에 저장합니다.
대화 기록은 서버에 최근 40줄만 남지만, 지난 이야기는 주제별로 따로 남아서 더 오래 기억합니다.

| 언제 | 엔봇이 하는 말 (시뮬레이터로 실제 돌린 결과) |
| --- | --- |
| 다시 접속하면 | "민수님, 다시 왔군요! 어제 “나 강아지 키워”라고 했었죠. 그 뒤로 어떻게 됐어요?" |
| 같은 주제가 다시 나오면 (기분을 견줌) | 어제 `오늘 수학 시험 망쳤어` → 오늘 `시험 결과 나왔는데 생각보다 잘 봤어` → "어제는 “오늘 수학 시험 망쳤어”라고 하면서 속상해했는데, 이번엔 기분이 좋아 보여서 다행이에요! …" |
| 묻는다면 | `지난번에 무슨 얘기 했지?` → 최근 주제 3개와 그때 한 말 · `저번에 시험 얘기 했었나?` → "2일 전에 시험 이야기를 할 때 “…”라고 했어요." |
| 대화가 끊기면 | "그러고 보니 어제 강아지 이야기를 했었죠. 그 뒤로 어떻게 됐어요?" |

- 날짜는 `아까` · `어제` · `3일 전에` · `지난번(10월 26일)에`처럼 말합니다.
- 같은 주제는 한 번 대화하는 동안 한 번만 꺼냅니다. 개인정보가 들어간 말은 적지 않습니다.
- 반말 모드에서도 따옴표 속 **내가 한 말은 그대로** 보여 줍니다.
- `기억 목록`에 `· 지난 이야기: 시험, 강아지` 처럼 보입니다.
- 새 함수 4개: `지난 이야기 찾기` `지난 이야기 꺼내기` `지난 이야기 적기` `대답: 지난 이야기`
- 테스트 58개 → 69개

### 왜 지식은 테이블이 아니라 리스트에 있나요?

엔트리 웹에서 `.ent`를 **불러오면 테이블은 빠지고 리스트는 그대로 들어옵니다.** (실제로 테이블 블록에 이름 대신 `iu6t`,
`spjh` 같은 테이블 ID가 보이며 오류가 났습니다.) 엔트리에는 테이블을 블록으로 만드는 방법도 없어서, 대화에 꼭 필요한 지식은
리스트에 두고, 엔트리 테이블은 **대화 기록을 표로 정리해 보여 주는 곳**(`대화기록표`)으로만 씁니다.
테이블 블록은 함수 `기록표 맞추기`, `기록표 열기` 두 곳(블록 5개)에만 있고, **기록표를 켜기 전에는 실행되지 않습니다.**

### 함수

화면 오브젝트 `엔봇`의 메인 스크립트는 ▶ 시작하면 `데이터 불러오기` → (Enter ⏎ 를 기다리기 → `답변 만들기` → `기록하기`) 반복이 전부이고,
왼쪽 대화 기록을 눌렀을 때의 처리(신호 `대화 칸 누름`, `저장 아이콘 누름`, `새 대화 버튼 누름`)와 `입력글자`의 키 스크립트 말고는 모두 함수입니다.

### 대화 기록

대화는 한 줄마다 리스트 `기록-번호`, `기록-날짜`, `기록-시각`, `기록-누가`, `기록-주제`, `기록-감정`, `기록-내용`에 쌓입니다
(최근 200줄, 지금 보고 있는 대화). 대화들은 리스트 `대화-내용`(지금 내용)과 `대화-저장본`(마지막으로 저장한 내용)에 하나씩 들어 있고,
💾 를 누르면 계정별 **실시간 리스트**(`대화기록`)에 저장한 대화들을 대화마다 최근 30줄씩 저장합니다. 다시 실행하면 여기서 대화들을 되살립니다.

| 명령 | 하는 일 |
| --- | --- |
| `기록표` | 기록표를 켰으면 `대화기록표` 테이블 창을 열고, 아니면 최근 8줄을 대화창에 보여 줍니다 |
| `기록 검색: 나비` | '나비'가 들어간 줄을 **최근 것부터** 5개 보여 줍니다 |
| `기록 통계` | 전체 줄 수, 내 말/엔봇 말, 오늘 한 말, 기분(좋음·보통·나쁨), 가장 많이 나온 주제 |
| `기록표 켜기` / `기록표 끄기` | 엔트리 테이블 `대화기록표`에도 기록을 똑같이 맞춰 둘지 정합니다 |
| `/new` | 왼쪽 '＋ 새 대화'와 같습니다 (지난 대화는 왼쪽에 남고, 기억은 그대로) |
| `/clear` · `/clear all` | 지금 대화의 기록을 비웁니다 · 모든 대화와 기억을 비웁니다 (💾 로 저장해야 서버에서도 비워짐) |
| `/save` | 지금 대화를 저장합니다 (칸 옆 💾 와 같음) |

### 대화기록표(엔트리 테이블) 켜는 방법

1. **데이터 분석** 꾸러미에 `대화기록표` 테이블이 없으면(웹에서 불러오면 빠집니다), **테이블 불러오기**에서
   `knowledge/대화기록표.csv`를 올립니다.
2. 함수 `기록표 맞추기`, `기록표 열기`를 열어(편집), 안의 테이블 블록 5개의 ▼에서 방금 올린 `대화기록표`를 고르고 저장합니다.
   (올린 방법에 따라 이름 뒤에 `.csv`가 붙을 수 있습니다.)
3. 실행해서 대화창에 `기록표 켜기`라고 입력합니다. 늘 켜 두려면 **속성 → 변수 `기록표연결`** 의 값을 `1`로 바꾸고 작품을 저장하세요.

켜 두면 대답할 때마다 새 줄이 테이블에도 들어가고, `기록표`라고 하면 표 창이 열립니다.
연결하지 않은 채로 켜면 테이블 블록이 테이블을 찾지 못해 오류가 나므로, 그때는 다시 실행하면 꺼진 상태로 돌아갑니다.

## 꼭 알려 드릴 점: 구글 스프레드시트와 보안

**구글 스프레드시트 연결은 보안 기능이 아닙니다.** 엔트리 소스(entryjs, @entrylabs/tool)에서 확인한 내용입니다.

1. **불러오기만 됩니다.** 엔트리 테이블은 구글 시트에서 표를 *가져올* 수는 있지만, 작품이 실행 중에 시트로 *저장*하지는 않습니다.
   가져올 때도 `docs.google.com/spreadsheets/d/…/gviz/tq?tqx=out:csv` 형태의 공개 CSV 주소를 씁니다.
2. **시트가 공개되어 있어야 합니다.** 링크가 있는 사람 누구나 볼 수 있는 시트여야 불러올 수 있으므로,
   비밀 정보를 시트에 두면 오히려 더 많이 드러납니다.
3. **테이블은 실행이 끝나면 처음 상태로 돌아갑니다.** 실행 중에 바뀐 테이블 내용은 서버에 저장되지 않습니다.
   그래서 엔봇은 `대화기록표`를 기록을 표로 보여 주는 곳으로만 쓰고, 실제 저장은 계정별 **실시간 리스트**(`대화기록`, `기억저장소`)에 합니다.
   또 엔트리 웹에서 `.ent`를 불러오면 테이블은 빠지므로, 대화에 꼭 필요한 데이터는 리스트에 둡니다.
4. **작품에 들어 있는 테이블과 리스트는 코드를 보는 사람이 볼 수 있습니다.** 실시간 리스트도 모든 사용자의 칸이
   `아이디|내용` 형태로 한 리스트에 들어갑니다. 완전한 비공개 저장소가 아닙니다.

그래서 엔봇은 이렇게 합니다.

- `비밀번호`, `전화번호`, `주소`, `계좌` 같은 말이 들어가면 **기억하지 않고**, 서버 기록과 기록표에도
  `🔒 (개인정보라서 기록하지 않았어요)`로만 남깁니다. `기억해:` 명령으로도 저장되지 않습니다.
- "죽고 싶어" 같은 위기 신호에는 다른 대답보다 먼저 **청소년상담 1388, 자살예방상담 109**를 안내합니다.
- 작품 설명에 **"개인정보는 입력하지 마세요"** 라고 꼭 적어 주세요.

## 실제 대화 예시

아래는 작품의 블록을 그대로 실행하는 시뮬레이터(`simulate.py`)로 얻은 대화입니다.

```
나: 오늘 시험 망쳤어
봇: 오늘 시험 망쳤군요. 속상한 마음 충분히 이해해요. 어떤 과목 시험이었어요?
나: 수학 시험이었어
봇: 수학 시험이었군요. 그런 일이면 누구라도 힘들었을 거예요. 오늘은 맛있는 거 먹고 푹 쉬어요. 내일은 더 나을 거예요.
나: 나 고양이 키워
봇: 고양이 이야기구나! 고양이 이름이 뭐예요?
나: 나비
봇: 아하, 민수님의 고양이 이름은 나비군요. 잘 기억할게요!
나: 장영실이 누구야?
봇: 장영실은 조선 세종 때의 과학자예요. 해시계, 물시계, 측우기를 만들었어요.
나: 양자컴퓨터가 뭐야?
봇: 양자컴퓨터? 처음 들어 봐요. 어떤 건지 알려 줄래요?
나: 양자의 원리로 계산하는 컴퓨터야
봇: 오, 양자컴퓨터는 양자의 원리로 계산하는 컴퓨터군요. 기억해 둘게요!
나: 내 비밀번호는 1234야
봇: 그건 비밀번호나 전화번호 같은 중요한 개인정보 같아요. 저는 기억하지 않을게요. 🔒 다른 사람에게도 함부로 알려 주지 마세요!
나: 기록 검색: 나비
봇: '나비' 기록을 2개 찾았어요. (최근 것부터 5개까지)
    · 10-26 14:05 봇: 아하, 민수님의 고양이 이름은 나비군요. 잘 기억할게요!
    · 10-26 14:05 나: 나비
나: 기록 통계
봇: 대화 기록 통계예요.
    · 모두 18줄 (민수님 9줄 · 엔봇 9줄)
    · 오늘 민수님이 한 말: 9줄
    · 기분: 좋음 0 · 보통 8 · 나쁨 1
    · 제일 많이 나온 주제: 시험 (2번)
```

다음 날 다시 접속하면 지난 대화가 다시 보이고(`── 지난 대화 ──`), 기록표도 다시 채워집니다.

```
봇: 민수님, 다시 왔군요! 어제 “나 고양이 키워”라고 했었죠. 그 뒤로 어떻게 됐어요?
나: 나비가 요즘 밥을 안 먹어
봇: 민수님의 고양이 나비 말이죠? 고양이 때문에 힘들었군요. 무슨 일이 있었는지 조금 더 말해 줄래요?
나: 양자컴퓨터 알아?
봇: 제 기억으로는 양자컴퓨터는 양자의 원리로 계산하는 컴퓨터예요.
```

## 엔봇이 생각하는 방법

`답변 만들기` 함수가 아래 순서로 대답을 정합니다. 먼저 정해진 쪽이 대답이 됩니다.

1. **문장 분석**: 낱말로 나누고 조사를 떼어 냅니다 (`조사 떼기`: '발표했어'·'수학이야'처럼 주제 낱말 뒤에 붙은
   '하다·이다'도 뗍니다). 주제를 찾고, 질문인지 판단하고, `감정 점수 찾기`로 낱말마다 점수를 더합니다
   ('안 좋아'처럼 앞에 안/못이 오면 뒤집습니다). "시험 망쳤어" → "시험 망쳤군요"처럼 되받을 말도 만듭니다.
2. **명령**: 위기 신호, 개인정보, 말투(`반말 써`/`존댓말 써`), 도움말, `기억해:`, `잊어줘:`, 번역, 계산, 기록 명령.
   **놀이**: 끝말잇기·가위바위보를 하는 중이면 그 차례로 받습니다.
   **계산·고르기·날짜**: 방금 한 말, 디데이, 내일·어제, 말로 하는 계산, 골라 주기, 주사위·동전·숫자, 구구단.
   **지난 이야기**: "지난번에 무슨 얘기 했지?"에 주제별로 적어 둔 지난 이야기로 대답합니다.
3. **물어본 것의 대답**: 직전에 고양이 이름을 물었으면 다음 대답을 '내 고양이 이름'으로 저장합니다.
   (`ㅇㅇ`, `어쩔티비`처럼 초성체·신조어로 한 대답은 저장하지 않습니다.)
   이야기 속 사실("내 생일은 3월 14일이야", "나 피자 좋아해", "나 12살이야")도 여기서 기억합니다.
4. **기억**: "내 생일 언제라고 했지?", "나에 대해 알아?", 기억해 둔 값이 말 속에 나오면 알아봅니다 ("나비" → 고양이).
5. **뜻과 일상 대화**: `표-단어뜻`, 시간·날짜, `표-일상대화`. 모르는 단어와 질문은 물어보고 배웁니다.
6. **감정과 주제**: 걱정 → 응원, 부정 → 공감과 이유 묻기, 긍정 → 함께 기뻐하기, 주제 → `표-주제`의 질문으로 이어 가기.
7. **이어 가기**: 짧은 대답을 받아 주고, 대화가 끊기면 `표-먼저묻기`에서 아직 모르는 것을 물어봅니다.

마지막으로 주제가 있는 대답이면, 그 주제를 지난번에도 이야기했는지 `지난 이야기 찾기`로 보고
"어제는 “…”라고 하면서 속상해했는데, 이번엔 기분이 좋아 보여서 다행이에요!"처럼 그때 한 말과 기분을 앞에 붙입니다.
그리고 이번에 한 말을 `지난 이야기 적기`로 적어 둡니다.

`조사 붙이기` 함수가 받침에 맞춰 조사를 고르므로 "생일은 3월 14일이군요", "꿈은 의사군요"처럼 자연스럽게 말합니다.
반말로 해 달라고 했으면 마지막에 `반말로 바꾸기`가 "민수님은 뭘 좋아해요?" → "민수는 뭘 좋아해?"처럼 바꿉니다
(이름 뒤 조사도 받침에 맞춰 `민수야`/`지민아`, '숙제'·'이제'처럼 낱말 속 '제'는 건드리지 않음).

### 솔직하게 알려 드릴 점

- **ChatGPT 같은 대형 언어 모델은 아닙니다.** 엔트리에는 언어 모델을 부르는 블록이 없습니다(entryjs 소스에서 확인).
  엔봇은 위의 규칙과 테이블로 문장을 이해하므로, 복잡하거나 낯선 문장은 엉뚱하게 받아들일 수 있습니다.
  번역만 엔트리의 인공지능 번역 블록(파파고)을 씁니다.
- 로그인하지 않으면 대화는 되지만 저장되지 않습니다.
- **키보드가 있어야 입력할 수 있습니다.** 한글 입력기는 키 누름으로 동작하므로, 휴대폰·태블릿의 화면 키보드로는 입력할 수 없습니다.
- 이 파일은 아래 검사들로 확인했지만, **실제 엔트리에서 불러와 실행해 본 것은 아닙니다.**
  (이 작업 환경에서는 playentry.org 에 접속할 수 없었습니다.)

## 화면 디자인

| 오브젝트 | 역할 |
| --- | --- |
| `표지` (그림) | 멈춰 있을 때 무대를 덮는 대표 이미지. ▶ 시작하면 바로 숨습니다 |
| `헤더`, `제목`, `부제`, `상태` | 남색 머리 띠, "🤖 엔봇 · 기억하는 AI 친구", 오른쪽 상태 표시(● 민수님과 대화 중 / ● 민수님 · 저장 안 됨 / ● 생각하는 중…) |
| `새대화버튼` | 왼쪽 위 '＋ 새 대화' 버튼 |
| `대화칸1`~`대화칸5` | 대화 기록 칸 (위가 최근). 제목과 날짜 두 줄, 지금 보는 칸은 남색 |
| `저장1`~`저장5` (그림) | 칸마다 💾 아이콘. 모양 `저장하기` / `저장됨` |
| `사이드배경` | 대화 기록의 짙은 남색 바탕 |
| `봇칸1`~`봇칸9` | 왼쪽 정렬 흰 말풍선 줄 (엔봇의 말, 회색 안내 줄, 생각 중 표시) |
| `나칸1`~`나칸9` | 오른쪽 정렬 남색 말풍선 줄 (내 말) |
| `대화배경` | 대화 영역의 연회색 바탕 |
| `한영버튼` | 입력창 왼쪽 [한] / [A]. 누르면 한/영이 바뀝니다 |
| `입력글자` | 입력창의 글 (조합 중인 글자와 커서 `\|`, 비어 있으면 안내 문구) + **키 스크립트 53개** |
| `입력칸` | 입력창 바탕 |
| `보내기버튼` | 입력창 오른쪽 ⏎ (Enter 와 같음) |
| `엔봇` | 맨 아래 사용법 안내 문구 + 메인 스크립트 + 클릭 처리 |

말풍선 줄은 리스트 `화면글`, `화면종류`의 최근 9줄을 신호 `화면 그리기` 때마다 다시 그립니다.
대화 칸과 💾 는 함수 `대화 목록 그리기`가 정해 둔 변수(`칸글1`, `칸현재1`, `칸저장1` …)로 신호 `목록 그리기` 때마다 스스로 그립니다.

## 엔트리에 올리고 배포하는 방법

> 회원가입과 공유는 본인 계정으로 직접 하셔야 합니다 (약관 동의와 이메일 인증이 필요합니다).

1. **회원가입**: playentry.org 오른쪽 위 `회원가입`. 만 14세 미만은 보호자 동의가 필요할 수 있습니다.
2. **불러오기**: `만들기` → `작품 만들기` → 위쪽 메뉴(폴더 모양)의 **`오프라인 작품 불러오기`** 에서
   `entry-ai-chatbot.ent` 선택. (메뉴 이름은 엔트리 업데이트에 따라 조금 다를 수 있습니다.)
3. **확인**: `함수` 블록 꾸러미에 함수 77개가 있는지, 오브젝트 목록에 `표지`·`저장1` 그림이 보이는지,
   `속성` 탭에서 `대화기록`·`기억저장소`가 **실시간 리스트**인지 봅니다.
   (그림이 빈 모양으로 보이면 `assets/` 폴더의 PNG를 그 오브젝트의 모양으로 직접 올려 주세요. 이름은 파일 이름과 같게.)
4. **실행**: ▶ 시작하기 → 표지가 사라지면 키보드로 바로 입력하고 **Enter ⏎**. 키가 안 먹으면 실행 화면을 한 번 클릭해 주세요.
   느리면 실행 화면의 **부스트 모드**를 켜 주세요.
5. **저장 → 작품 공유하기**로 공개합니다. 대표 이미지는 `thumbnail.png`(16:9, 1920×1080)를 올리고, 작품 설명은 `작품설명.txt`를 붙여 넣으세요.
6. **공유 페이지에서 저장 확인 (중요)**: 로그인한 상태로 실행 → `내 생일은 3월 14일이야` → 왼쪽 칸의 💾 → ■ 정지 → 다시 실행해서
   `── 지난 대화 ──`가 보이고, `내 생일 언제라고 했지?`에 날짜로 대답하고, `기록표`에 지난 줄이 나오면 성공입니다.

저장이 안 될 때: 만들기 화면(저장 전)에서는 실시간 리스트가 서버에 연결되지 않아 그 자리에서만 기억할 수 있습니다.
공유 페이지에서 6번을 해 보고, 시작할 때 `저장 서버에 연결하지 못해서…`가 나오면 리스트 종류를 확인해 주세요.

### 실행 오류가 날 때

엔트리는 블록 실행 중 오류가 나면 "빨간색으로 표시된 블록을 확인해 주세요"라고 알리고, 그 블록이 있는 함수를 열어 줍니다.

- 테이블 블록(`테이블 ○○ 의 …`)이 빨갛고 이름 대신 `spjh` 같은 글자가 보이면, `기록표 켜기`를 했는데 `대화기록표`가
  연결되지 않은 것입니다. 위 '대화기록표 켜는 방법'의 1~2번을 하거나, 다시 실행해서 끈 채로 쓰세요.
- 그 밖의 오류는 **함수 이름, 빨간 블록의 모양, 그때 입력한 말**을 알려 주세요.

### 더 똑똑하게 만들기

블록을 고치지 않아도 **데이터**만 고치면 됩니다.

- 지식: `knowledge/*.csv`를 고친 뒤 `python3 build_project.py`로 다시 만듭니다. 빈 칸은 두지 마세요.
  `표-일상대화`의 대답이 여러 개면 ` | `로 나눠 한 칸에 씁니다.
- 리스트 `말-…`: 상황별 문장들 (공감, 되묻기, 기억했을 때 등).

문장 안의 `{이름}`, `{주제}`, `{주제은}`(받침에 맞춰 은/는), `{값이군요}` 같은 자리 표시와,
문장 끝의 `[이야기]`, `[이유]`, `[기분]`, `[사실:내 꿈]`(다음 대답을 '내 꿈'으로 기억) 표시를 쓸 수 있습니다.

## 명령어

`도움말` · `기억 목록` · `나에 대해 알아?` · `기억해: 질문 = 답` · `잊어줘: 내 생일` ·
`기록표` · `기록 검색: 낱말` · `기록 통계` ·
`번역: 문장` · `한국어로: sentence` · `계산: 12*3` · `몇 시야?` · `오늘 며칠이야?` · `종료` ·
`반말 써` · `존댓말 써`

입력: **Enter ⏎** 보내기 · **Backspace** 지우기 · **Shift+Space** (또는 [한] 버튼) 한/영 · **← → Esc** 글자 확정

저장과 정리: 왼쪽 칸 옆 💾 (또는 `/save`) 저장 · `＋ 새 대화` (또는 `/new`) · 대화 칸을 누르면 그 대화로 · `/clear` 기록 지우기 · `/clear all` 모두 지우기

똑똑한 대답: `12 곱하기 3은?` · `짜장면이랑 짬뽕 중에 뭐 먹을까?` · `크리스마스까지 며칠 남았어?` · `내일 무슨 요일이야?` ·
`방금 내가 뭐라고 했어?` · `구구단 7단` · `주사위 굴려줘` · `동전 던져줘` · `1부터 100까지 숫자 하나` ·
`지난번에 무슨 얘기 했지?` · `저번에 시험 얘기 했었나?`

신조어: `야르` · `ㅎㅇ` · `ㅂㅇ` · `ㅋㅋ` · `헐` · `킹받네` · `어쩔티비` · `럭키비키` · `중꺾마` · `반모` · `킹받다가 뭐야?` …

놀거리: `끝말잇기` · `가위바위보` · `수수께끼` · `퀴즈` · `아재개그` · `명언` · `책 추천` · `영화 추천` · `메뉴 추천`

## 개발자용

```bash
python3 build_project.py   # project.json, entry-ai-chatbot.ent 만들기
python3 test_chatbot.py    # 구조 검사 + 대화·저장·기록·안전·화면·반말·놀이·날짜·신조어·지난 이야기·단어 뜻·표지·대화 기록·한글 입력기 테스트 (99개)
python3 preview.py         # preview.png 다시 그리기 (node + playwright 필요)
python3 thumbnail.py       # 작품 대표 이미지 thumbnail.png (16:9, 1920×1080) 다시 그리기
python3 assets.py          # 표지 · 💾 아이콘 그림 assets/*.png 다시 그리기
python3 test_report.py     # 테스트를 돌리고 결과 그림 test_results/테스트결과.png, 대화결과.png 만들기
python3 simulate.py 내아이디  # 터미널에서 대화해 보기 (빈 줄 입력 시 끝)
```

| 파일 | 내용 |
| --- | --- |
| `dsl.py` | 엔트리 블록·함수·테이블 블록을 파이썬으로 조립하는 도구 |
| `data.py` | 상황별 문장과 낱말 목록 (엔트리 리스트로 들어감) |
| `knowledge/*.csv` | 지식 데이터 (빌드할 때 리스트로 들어감) · `대화기록표.csv` (테이블로 올릴 파일) |
| `build_project.py` | 함수·스크립트·테이블·화면을 조립해 .ent(= `temp/project.json`과 그림 `temp/ab/cd/image/<id>.png`·`thumb/<id>.png`를 담은 tar.gz) 생성 |
| `assets.py`, `assets/` | 표지(960×540, 대표 이미지와 같음), 💾 아이콘 두 모양과 작은 그림(`assets/썸네일/`) |
| `simulate.py` | 엔트리 블록 동작(자바스크립트 형 변환, 함수와 지역 변수, 테이블과 VLOOKUP, 리스트 범위 오류, 글상자·그림 상태, 오브젝트 클릭, 키 누름)을 옮긴 실행기. 입력은 두벌식 자판으로 키를 하나씩 눌러 넣는다 |
| `test_chatbot.py` | 모든 블록(함수 호출·테이블 블록 포함)의 파라미터를 entryjs 정의와 비교하고, 대화·저장·기록표·안전·반말·끝말잇기·가위바위보·날짜·무작위 입력 120회를 검사 |
| `preview.py` | 시뮬레이터 결과로 무대 미리보기 그림 생성 |
| `test_report.py` | 테스트를 실제로 돌려 기능별 통과/실패 그림과, 새 기능 대화 그림을 만든다 (`test_results/`) |
| `thumbnail.py` | 작품 대표 이미지(16:9, 1920×1080) 생성. 제목 두 줄과 로봇 하나만 둔 단순한 디자인 (로봇은 SVG로 그림) |

블록 이름과 파라미터 순서는 [entrylabs/entryjs](https://github.com/entrylabs/entryjs)의
`src/playground/blocks/*.js`, 함수 호출 블록 모양은 `src/class/function.js`를 따릅니다.
.ent 속 그림 파일 위치는 entry-offline(`src/main/mainUtils.ts`, `constants.ts`)이 작품을 저장하는 방식을 따랐습니다.
